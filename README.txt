MIRZA OTP RECEIVER PANEL — GitHub Pages demo

1. Extract the ZIP.
2. Upload index.html to the root of your GitHub repository.
3. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the Pages URL after deployment.

This is a static frontend demo. Data is stored in the current browser only.
It cannot securely authenticate users, run a real shared wallet, verify JazzCash
payments, or provision real phone numbers / receive SMS. Those require a backend,
a secure database, server-side payment verification and an authorized provider API.
Do not store real secrets in index.html or GitHub.
